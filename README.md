A top-down action roguelike dungeon crawler for the [make.fun best-game-01 bounty](https://make.fun/bounty/best-game-01).

Clear procedurally generated dungeon floors by defeating all enemies. Collect coins, find hearts, and descend deeper — floors get harder with new enemy types and more obstacles.

## How to play

```sh
node serve.ts  # then open http://localhost:8080
```

**Controls:** WASD/Arrow keys to move, SPACE to attack. Touch controls supported on mobile.

## Entry

```sh
node main.ts  # copies game to /output
```
